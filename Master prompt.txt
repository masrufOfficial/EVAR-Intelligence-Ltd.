==================================================

Prevent:

XSS

IDOR

Path Traversal
Prototype Pollution
Open Redirects
Insecure Deserialization

File Upload Abuse

Never trust client-side input.

Use allowlists where possible.

Use strict schemas.

Never construct raw SQL from user input.
